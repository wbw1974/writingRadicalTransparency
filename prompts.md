I am experimenting with radical transparency. Help me to structure this project so that the following guidelines can be enforced:

1. All writing that will be published as part of any story lives in a directory where AI input should not be saved. This includes the ability to audit items generated in pre-writing and noting in a log that tracks where the human-crafted narrative departs from pre-writing.
2. A file that holds backstory and continuity rules, generated by human and AI co-work.
3. A generalizable setup that can be adapted and cloned to another story setup.
4. An archive of cutting room floor detritus. This can and should be mined for new ideas.
5. Github commits that track who did what.
